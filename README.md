# MyBizExco

AI-powered governance operating system for South African SMMEs — board
deliberations, governance scoring, compliance frameworks, meeting
management, and communication distribution, built for the FSCA/FAIS/POPIA
regulatory context.

## Status

Single-file vanilla JS application (`MyBizExco_21.html`), no framework or
CDN dependencies. This is the canonical source going forward.
